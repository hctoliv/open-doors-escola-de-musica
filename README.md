# Open Doors – Escola de Música

Site estático (HTML, CSS e JavaScript puros, sem build) da Open Doors – Escola de Música, Av. Sapopemba, 7906 – Vila Fátima, São Paulo.

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8000
```

## Publicação

Publicado pelo GitHub Pages a partir da branch `main`.
